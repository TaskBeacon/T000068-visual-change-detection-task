# Task Plot Brief

Title: Visual Change Detection Task  
Construct: visual working-memory capacity

## Rows

- SAME: the test array repeats every sampled color at the same locations.
- ONE COLOR CHANGE: the test array keeps all locations but replaces exactly one sampled color.

Set sizes 2, 4, 6, and 8 share the same participant-visible timeline. Use four squares in each representative row so the same/change relation is immediately readable.

## Timeline

- Fixation: central white `+` on dark screen, 500 ms.
- Memory: four uniquely colored squares around fixation, 100 ms.
- Retention: central white `+` only, 900 ms.
- Test: same four positions; SAME repeats all colors, ONE COLOR CHANGE alters exactly one square; F = SAME and J = CHANGE; 2000 ms max.

No feedback appears after the response.
